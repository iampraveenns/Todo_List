# 📝 Personal Note & Task Manager

A responsive full-stack note-taking and task management application designed for quick capture, organization, and daily productivity. 

🔗 **Live Deployment:** [RemaindMe on Netlify](https://remaindme.netlify.app/)

---

## 🚀 Features

- **Note & Task Management:** Create, view, edit, and delete notes or to-do items seamlessly.
- **Status Tracking:** Mark tasks as completed, pending, or archive finished items.
- **Fast & Responsive UI:** Built with Vite for instant loading, mobile responsiveness, and smooth client-side interactions.
- **Persistent Storage:** Backed by a dedicated REST API to keep notes synced across sessions.
- **Clean Interface:** Minimalist, distraction-free interface for effortless task entry.

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Modern CSS / Tailwind CSS
- **Backend:** Node.js, Express.js *(or Python Flask)*
- **Database:** MongoDB / SQLite
- **Deployment:** [Netlify](https://remaindme.netlify.app/) (Frontend), Render / Railway (Backend)
